১. app.listen()

এটা Express.js method, যা Node.js HTTP server তৈরি করে এবং নির্দিষ্ট port-এ লিসেন করতে শুরু করে।

সাধারণভাবে লিখি:

app.listen(port, callback)


callback তখন execute হয় যখন সার্ভার সফলভাবে শুরু হয়ে গেছে।

২. server
server = app.listen(port, () => { ... })


এখানে server হলো Node.js HTTP server object।

অর্থাৎ, app.listen() এই server object কে return করে, যা আমরা server নামের variable-এ ধরে রাখছি।

এই object দিয়ে পরে আমরা অনেক কাজ করতে পারি, যেমন:

server.close() → সার্ভার বন্ধ করা

server.address() → কোন port এ লিসেন করছে সেটা জানা

অন্যান্য low-level Node.js server operations

সংক্ষেপে

app.listen() → সার্ভার চালু করে এবং HTTP server object return করে।

server → সেই returned object।

১. server.close()

এটা Node.js এর HTTP server method।

কাজ:

নতুন request আর গ্রহণ করবে না।

চলমান সব request শেষ হওয়া পর্যন্ত অপেক্ষা করবে।

অর্থাৎ, সার্ভার gracefully বন্ধ হওয়ার প্রক্রিয়া শুরু করে।

২. Callback () => { process.exit(1) }

যখন সব চলমান request শেষ হয়ে যায় এবং server সম্পূর্ণ বন্ধ হয়ে যায়, তখন এই callback execute হয়।

process.exit(1) এর কাজ: Node process কে exit code 1 দিয়ে বন্ধ করা।

1 সাধারণত signal করে error বা abnormal shutdown।

0 হলে normal shutdown।

unhandled promise rejection ধরল।

console.log দেখাবে warning।

server.close() নতুন connection বন্ধ করবে, চলমানগুলো শেষ করবে।

সব শেষ হলে callback চলবে।

process.exit(1) সার্ভার ও Node process বন্ধ করবে।

process.exit(1) হলো Node.js-এর process control function। ধাপে ধাপে বুঝাই:

1️⃣ process.exit() কি?

process.exit() Node.js process immediately terminate করে।

মানে, যে Node.js program চলছিল, তা তৎক্ষণাৎ বন্ধ হয়ে যাবে।

2️⃣ Argument এর মান (0, 1, বা অন্য কোনো number)

0 → successful exit (কোনো error ছাড়া শেষ)

1 → failure exit (কোনো error বা exception-এর কারণে বন্ধ)

সাধারণভাবে:

process.exit(0); // ঠিকঠাক শেষ হয়ে গেছে
process.exit(1); // কোনো error-এর কারণে বন্ধ

3️⃣ Practical use

তুমি যেমন দেখেছো:

server.close(() => {
    process.exit(1);
});


server.close() → সার্ভারের সকল connection gracefully বন্ধ করে।

তারপর process.exit(1) → Node.js process কে exit code 1 সহ বন্ধ করে, যা বোঝায়: “error-এর কারণে সার্ভার বন্ধ হয়েছে।”

সংক্ষেপে:
process.exit(1) বলছে: “Node.js process এখনই বন্ধ করো এবং exit code 1 দিয়ে signal দাও যে এটা error-এর কারণে বন্ধ।”

1️⃣ server.close()

Example:

server.close(() => {
  console.log("Server closed gracefully.");
});

2️⃣ process.exit()

Exit code (0 = success, 1 = error) দিতে পারা যায়।

Example:

process.exit(1); // Exit code 1 দিয়ে process বন্ধ

2️⃣ Server কখন on হয়?

Server তখনই চালু হয় যখন আপনি app.listen(port) কল করেন।

এই মুহূর্তে Node.js process এর event loop active থাকে এবং server HTTP requests গ্রহণ করার জন্য ready।

process.exit(1) program terminate করে ফেলবে → তাই server.close function এর ভেতরে ঢোকার সুযোগই পাবে না।

Callback দিলে → function body execute হবে → তারপর callback → তারপর exit।

সরাসরি দিলে → process.exit(1) সাথে সাথেই program terminate করে ফেলবে → তাই function body (server.close called) আর execute হবে না।
